防犯ノート投稿

このツールは、運営者が自分のYouTubeチャンネルへ、自分で作った動画を予約投稿するための個人用ツールです。運営者本人のパソコンの中で、決まった時刻に自動で動きます。運営者以外の人は使いません。

できること

  • 運営者が作った動画を、運営者のYouTubeチャンネルへ「非公開」でアップロードし、公開日時を予約する
  • 動画のタイトル・説明・タグを設定する
  • 一部のチャンネルでは、字幕とサムネイルも設定する
  • アップロードの前に、許可されたチャンネルが正しい投稿先かどうかを確認し、違う場合は1本もアップロードせずに止まる

このツールは、動画の削除、コメントの読み書き、再生回数などの分析情報の取得は行いません。

使っているチャンネル

  • 怪異検証室
  • 女性探偵の防犯ノート

Googleアカウントの情報の扱い

このツールは、YouTube Data API v3 を使います。アクセスするのは、運営者本人のYouTubeチャンネルの名前・IDと、運営者がアップロードする動画だけです。くわしくはプライバシーポリシーに書いています。
